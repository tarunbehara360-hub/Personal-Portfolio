# Personal Portfolio

## 📌 Project Overview

Personal Portfolio is a responsive website created to showcase my profile, technical skills, projects, education, and contact information.

## 🎯 Objective

The main objective of this project is to build a simple and professional personal portfolio website using front-end web technologies.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Personal introduction
- About section
- Technical skills
- Projects section
- Education details
- Contact section
- Responsive design
- Interactive elements using JavaScript
